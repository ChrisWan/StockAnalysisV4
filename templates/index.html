Benchmark Actions
Refresh or inspect the benchmark store

Run the sector refresh when you want current peer medians, then inspect the saved file and history below.

Note: This process analyzes 110 stocks across 11 sectors and usually takes 2-3 minutes. You only need to run it occasionally unless you want fresher sector medians.
Benchmark Status

File health, calculation metadata, and recent refresh history.

How it works: The system fetches data for 10 representative stocks per sector, calculates the median for P/E, P/B, P/S, ROE, and Profit Margin, then saves the results to sector_benchmarks.json for fast access. Stocks are scored based on how much better/worse they are compared to their sector median.

Backtest Parameters
Choose a symbol and window

Uses SEC EDGAR filings as they existed at each historical date, not what's known today - see the note below.

Known limitation: sector benchmark medians (P/E, P/B, etc.) always use today's sector_benchmarks.json for every historical evaluation date, not a historical snapshot - no historical benchmark store exists yet. Technical signals and EDGAR-sourced fundamentals are genuinely point-in-time; sector comparison is an approximation that drifts further from accurate the older the backtest window.
